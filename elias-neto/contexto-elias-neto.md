## Objetivo
Criar um protótipo de Landing Page moderna em React + Tailwind CSS para o escritório Elias Neto Associados (https://eliasneto.com.br/).

## Requisitos Visuais
- Estilo: Moderno, Minimalista, Alto Contraste, Profissional (Autoridade).
- Cores Primárias: Fundo Marinho Profundo ou Preto (#000000/#0F172A), Fundo de Leitura Branco (#FFFFFF).
- Cores de Destaque (Baseada no Print): Vermelho Carmesim Intenso (#8B0000 ou #A52A2A). *Utilizar como cor de 'Prestígio' e CTA.*
- Tipografia: Títulos Serif elegantes (autoridade), corpo Sans-serif (modernidade).
- Responsividade: Mobile-first obrigatório.

## Estrutura de Componentes (Utilizar Lucide React)
1. Navbar: Logotipo e botão de contato rápido (Carmesim).
2. Hero: Headline estratégica + Subheadline + Botão de agendamento (Carmesim).
3. Services: Grid de cards com ícones e hover rubro (Scale, Shield, Gavel, Briefcase).
4. Testimonials: Seção de depoimentos clean com aspas rubras.
5. Footer & CTA: Formulário e botão WhatsApp flutuante (Carmesim).
6. Social SEO: Configuração Helmet/index.html para Open Graph (WhatsApp/Instagram) com banner rubro.

## Regras de Implementação
- Código Semântico: Seguir padrões W3C.
- Tailwind CSS: Usar classes utilitárias.
- Placeholders: Usar imagens do Unsplash via URL.
- Interatividade: Transições suaves de hover (especialmente o vermelho).
